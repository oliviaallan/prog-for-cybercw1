# Programming for Cyber Security - Coursework 1

Coursework Repository Description:

This repository contains my source code and solutions for all tasks required for Coursework 1 of the Programming for Cybersecurity module I am currently partaking in. It includes five tasks in which various cybersecurity checks are run, such as authenticating user login information, running various security functions to check things like successful and unsuccessful login attempts, validating IP addresses, recording and displaying security information to be presented to the user, and also generation of random passwords. Below is a further breakdown of each individual task.

Individual Task Descriptions:

Task 1 requires development of a security tool, a program to authenticate the user's login details and provide a menu to perform various security functions. The first is a security event counter, which asks for a password ten times and then displays the percentage correct and incorrect entries are made. The second is a brute-force simulator, asking for a password until the correct one is entered of it runs out of attempts.  The third is a login authenticator, which asks for a username and password and authenticates until correct of three attempts have been made. The fourth function allows the user to exit.

Task 2 is for a security event logger, which asks for and authentications user login information. It captures and displays whether login was successful or unsuccessful, along with an event ID, username, IP address, and a timestamp of when the login was attempted.

Task 3 is for an IP address validator in which it asks the user for an IP address and checks it is in valid format. It checks the user input against a series of criteria and provides an appropriate message on whether what the user entered is valid or invalid.

Task 4 is for a security incident manager, which creates a record for a security incident and modifies it in various ways through the use of dictionaries.

Task 5 is for a set of reusable cybersecurity functions through two different programs. The first program contains three functions, programmed firstly to ask for a password and check it against a set of requirements, the second will check an IP address against a set of requirements, the third will generate a random password meeting a certain set of criteria. The second program asks for the user's input and runs each of the functions provided in the first program, this is possible by importing the first program into the second.
