Description of Program:

The task runs a security tool program to authenticate the user's login details and provide a menu to perform various security functions. There are four options available - the first is a security event counter, which asks for a password ten times and then displays the percentage correct and incorrect entries are made. The second is a brute-force simulator, asking for a password until the correct one is entered of it runs out of attempts.  The third is a login authenticator, which asks for a username and password and authenticates until correct of three attempts have been made. The fourth function allows the user to exit.

How to Run:

- Open terminal in the security-tool.py file located in the project folder.
- Run command " python3 security-tool.py ".
- Follow instructions given by the program.
